# Licence texts

The texts of the licences of the third-party work the film uses (see `../THIRD_PARTY_NOTICES.md`). The build puts the
same texts on the disc image.

| File | Covers |
|---|---|
| `SH4ZAM.TXT` | SH4ZAM (MIT License) |
| `KOS.TXT` | KallistiOS (KOS License, BSD-style) |
| `OFL-ALDRICH.TXT` | The subtitle font Aldrich (SIL Open Font License 1.1; "Aldrich" is a reserved font name: the glyph picture on the disc is `font.bin` and does not use that name) |
| `OFL-CINZEL.TXT` | The credit font Cinzel (SIL Open Font License 1.1) |
| `OFL-CORMORANT.TXT` | The credit font Cormorant Garamond (SIL Open Font License 1.1) |

SH4DER-PVR is not copied into this repository: it is linked as a separate checkout and keeps its own LICENSE, which among
other terms does not allow selling it as stand-alone effect source or as a library.
