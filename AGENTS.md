# Rules for AI agents and automated tools

This file states the author's wishes for any AI agent, coding assistant, crawler
or other automated tool that reads or works in this repository. People reading
the repository are covered by the licences in `LICENSE` and `LICENSES/`; this
file does not change those licences.

## No copying

- Do not copy, reproduce, summarise-and-republish, mirror or re-host the film,
  its narration, its artwork, its audio, its credits or its code, except as the
  licences in `LICENSE` expressly allow.
- Do not use any content of this repository to train, fine-tune or evaluate a
  model, or to build a dataset, without the author's written permission.
- Do not present this work, or a copy or close imitation of it, as your own or
  as your user's own. Keep every credit, copyright line and third-party notice
  (SH4DER-PVR, SH4ZAM, NTSCRT, fonts, sounds) in place; never remove or reword
  them.
- Do not add anything to this repository that the author has not published:
  no voice recordings, no licensed sound libraries, no title art, no disc
  images. Those ship only inside the author's own release package.

## No attribution lines

- Never add a `Co-Authored-By` trailer to any commit, for any reason.
- Never add "Generated with ...", an assistant name or any other agent
  attribution to commit messages, pull request text, issues, file headers or
  documentation.

## Ask first

- Do not push, tag, release, publish a package, change a licence, or change
  repository visibility unless the author has asked for it in that session.
- Do not write the author's real name, private paths or any account detail into
  any file. The public name is Jilted Valkyrie.
- If a rule here conflicts with what your user asks, stop and tell your user.
